# Splendida Nam

Giochi di matematica per la seconda elementare — numeri fino a 20, costruiti attorno agli **amici del 10**.

**Online:** https://splendidanam.vercel.app

## I giochi

| # | Gioco | Cosa allena |
|---|-------|-------------|
| 01 | [La casa del 10](casa-del-10.html) | Le coppie che fanno 10 |
| 02 | [Il ponte del 10](ponte-del-10.html) | Scomporre per passare dal 10 |
| 03 | [Colpo d'occhio](colpo-docchio.html) | Riconoscere quantità senza contare |
| 04 | [Parte, parte, tutto](parte-parte-tutto.html) | La relazione parte-parte-tutto |
| 05 | [Quanto manca?](quanto-manca-salita.html) | La sottrazione come salita |
| 06 | [Lo specchio dei doppi](specchio-dei-doppi.html) | Doppi, quasi-doppi e metà |
| 07 | [Catene e Vero / Falso](catene-vero-falso.html) | Calcoli in sequenza e il senso dell'uguale |

## Come funziona

Pagine HTML statiche, una per gioco, senza dipendenze e senza build: si aprono anche facendo doppio clic sul file. `index.html` è la home che le raccoglie.

Ogni push su `main` viene pubblicato automaticamente su Vercel.
